# Introduction to Python Programming and Databases

This repository contains projects completed as part of the **Introduction to Python Programming and Databases** course at **African Leadership University (ALU)**.

The projects provided hands-on experience with Python programming, object-oriented programming, data structures, file handling, databases, SQL, networking, APIs, ORM, and test-driven development.

## Technologies & Concepts

* **Language:** Python
* **Database:** MySQL
* **SQL:** Database creation, queries, joins, permissions, and relationships
* **ORM:** SQLAlchemy
* **Testing:** Unit testing and Test-Driven Development
* **Libraries:** NumPy
* **APIs:** GitHub API
* **Data Formats:** JSON and CSV
* **Shell:** Bash
* **Version Control:** Git & GitHub
