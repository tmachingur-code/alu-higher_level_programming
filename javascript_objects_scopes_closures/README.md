# JavaScript - Objects, Scopes and Closures

This project focuses on JavaScript **objects, classes, scopes, closures, inheritance, and prototypes**.

## Learning Objectives

- Create and use JavaScript objects and classes
- Understand `this`, `undefined`, and variable scope
- Understand closures and prototypes
- Use inheritance with `extends` and `super`
- Create and use class methods
- Work with arrays and functions
- Export and import functions using `module.exports` and `require()`

## Tasks

- **0–4:** Rectangle classes and methods
- **5–6:** Square classes and inheritance
- **7:** Count occurrences in a list
- **8:** Reverse a list without `reverse()`
- **9:** Use closures to count function calls
- **10:** Convert numbers between bases

## Requirements

- Node.js 14.x
- No `var`
- Use `class` notation where required
- All files must be executable
- Code must pass `semistandard`

## Run

```bash
./filename.js
```
