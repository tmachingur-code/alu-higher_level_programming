# JavaScript - Web jQuery

This project introduces jQuery for manipulating HTML elements, handling events, updating the DOM, and making API requests without reloading the page.

## Topics Covered
- Selecting and modifying HTML elements with jQuery
- Handling click events
- Adding, removing, and toggling CSS classes
- Updating text and lists dynamically
- Making HTTP requests using jQuery AJAX
- Working with API responses

## Requirements
- JavaScript
- jQuery 3.x
- Chrome 57 or later
- Semistandard
