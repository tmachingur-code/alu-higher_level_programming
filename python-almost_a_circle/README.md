# Python - Almost a Circle

This project reviews core Python object-oriented programming concepts by building a reusable class hierarchy consisting of `Base`, `Rectangle`, and `Square` classes. It covers inheritance, encapsulation, property validation, serialization and deserialization using JSON, file handling, `*args` and `**kwargs`, class and static methods, and comprehensive unit testing with the `unittest` module. The project emphasizes writing clean, modular, PEP 8-compliant code while implementing object creation, persistence, and testing in preparation for larger Python applications such as the AirBnB clone project.
