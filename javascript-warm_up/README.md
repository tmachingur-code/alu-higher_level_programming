# JavaScript - Warm Up

This project introduces the basics of JavaScript scripting using Node.js.

## Learning Objectives

By completing this project, I will learn how to:

* Run JavaScript scripts using Node.js
* Create variables and constants using `let` and `const`
* Understand JavaScript data types
* Use operators and expressions
* Use `if`, `if...else`, and `switch` statements
* Write and use loops
* Use `break` and `continue`
* Create and use functions
* Understand function return values and scope
* Work with arrays and objects
* Use arithmetic operators
* Import functions from another JavaScript file

## Technologies

* JavaScript
* Node.js 14.x
* Semistandard 16.x

## Project Structure

Each JavaScript file contains a solution to a specific task, covering different JavaScript fundamentals such as variables, arguments, loops, functions, recursion, objects, and modules.

## Requirements

* Ubuntu 20.04 LTS
* Node.js 14.x
* Semistandard 16.x
* All JavaScript files use the Node.js shebang:

```bash
#!/usr/bin/node
```

## Running the Scripts

Make a file executable:

```bash
chmod +x filename.js
```

Run it:

```bash
./filename.js
```

You can also run it directly with Node.js:

```bash
node filename.js
```

## Code Style

The project follows the Semistandard coding style with semicolons, as required by the project.

```bash
semistandard filename.js
```
